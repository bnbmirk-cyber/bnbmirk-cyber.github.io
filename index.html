Metro Social Hub

Metro Social Hub is a personal Windows application its owner uses to publish their own posts and videos and to view statistics for their own channels. It is not a public service.

Privacy Policy

With the owner's consent, the application connects to the owner's YouTube account and uses Google data only to upload videos chosen by the owner and to display statistics for the owner's channel. Data is stored only on the owner's computer, access keys are encrypted using Windows, and there is no application server. Data is not sold, shared with third parties, or used for advertising.

Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Access can be revoked at any time on the Google Account permissions page. Contact: @MetroN0x on Telegram.
